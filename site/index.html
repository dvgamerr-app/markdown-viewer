Fullscreen viewer

Every diagram gets a toolbar.

Inline, a diagram sits still in your document. Click fullscreen and it becomes something you can move around in, from the keyboard or the mouse.

  • /Find a node by name
  • MOverview map of the whole diagram
  • PPlay a sequence, journey or timeline
  • + - 0Zoom in, zoom out, reset
  • EscClose the popup, then leave fullscreen

Diagrams that play.

Mermaid journeys and timelines are redrawn in one calm style and play when you ask them to. DBML, a database schema language that is not part of Mermaid, is drawn by Nimbus as well.

Get started

Running in a minute.

  1. Install Nimbus Markdown from the Chrome Web Store.
  2. Open chrome://extensions, click Details on Nimbus Markdown and turn on Allow access to file URLs.
  3. Drag a .md file into the browser. For files on websites, add the site in Advanced Options.

FAQ

Questions before you install.

Why do I need to turn on "Allow access to file URLs"?

Chrome blocks every extension from reading local files until you allow it. Without that switch Nimbus can only render Markdown on websites you add. It is one toggle on the extension's Details page in chrome://extensions.

Does Nimbus upload my documents?

No. Rendering happens in your browser and your documents are not sent to a developer server. Emoji images load from a CDN, and your settings sync through your browser if sync is on. The privacy policy lists everything it handles.

Will it run on every website?

No. Website access is an optional permission. Nimbus only renders Markdown on the sites you add in Advanced Options, for example https://raw.githubusercontent.com.

Which diagrams are supported?

Every diagram type Mermaid 12 renders. Fullscreen, zoom and node search work on all of them. Sequence, state, journey and timeline diagrams also play step by step, and journey, timeline, gantt, pie, quadrant, git graph, C4, mindmap and requirement diagrams are redrawn in the Nimbus style. DBML is supported separately in dbml code blocks.

Does it work outside Chrome?

It installs from the Chrome Web Store on Chromium browsers such as Edge and Brave. A Firefox build is attached to each GitHub release, with some limits listed in the Firefox notes.

Is it really free?

Yes. Nimbus is MIT licensed open source, a maintained fork of Markdown Viewer by Simeon Velichkov. There is no paid tier.
