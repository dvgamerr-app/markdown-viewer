Fullscreen viewer

Every diagram gets a toolbar.

Inline, a diagram sits still in your document. Click fullscreen and it becomes something you can move around in, from the keyboard or the mouse.

  • /Find a node by name
  • MOverview map of the whole diagram
  • PPlay a sequence, journey or timeline
  • + - 0Zoom in, zoom out, reset
  • EscClose the popup, then leave fullscreen

Get started

Running in a minute.

  1. Install Nimbus Markdown from the Chrome Web Store.
  2. Open chrome://extensions, click Details on Nimbus Markdown and turn on Allow access to file URLs.
  3. Drag a .md file into the browser. For files on websites, add the site in Advanced Options.
# Release flow

```mermaid
flowchart LR
  pr([Pull request]) --> ci{Checks pass?}
  ci -->|yes| merge[Merge]:::focal
  ci -->|no| fix[Fix] --> pr
  merge --> tag[(Tag)] --> store([Web Store])
```
Save as flow.md, open it in Chrome and click fullscreen on the diagram.
